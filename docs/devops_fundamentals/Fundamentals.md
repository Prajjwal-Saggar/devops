# Devops LifeCycle

## Phases of Devops (4 Dev  , 4 Ops)

### Dev
1. Plan
2. Code
3. Build
4. Test

### Ops
1. Release
2. Deploy
3. Monitor
4. Operate


## 7 C's of DEVOPS

1. Continuous Development
2. Continuous Integration
3. Continuous Testing
4. Continuous Deployment
5. Continuous Monitoring
6. Continuous Feedback
7. Continuous Operating
