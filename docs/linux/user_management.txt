1. Creating a User
	* So to create a user we use the useradd commands 
	* Then to set the password for the new user we use the sudo passwd xyz(name of the new user)
	* sudo userdel xyz -> This is the command to delete the user
	* su xyz is used to switch between the user 
	* whoami is used to check who is the current user 
2. There will be times when you will not be able to delete the user so make sure you inspect the task that user
	is running or the process by the command "ps" if already in that user or ps -u xyz . Then kill that proces
	Command -> sudo kill -9 process_id(num) -> Here -9 is force kill
	Normal Kill -> pkill -u xyz
	Normal kill -> kill process_id(num)

3. Group Management 
	* sudo groupadd xyz(group_name)
	* sudo groupdel xyz
	* sudo usermod -g xyz(group_name) danny(user_name) -> This is used to assign the group to the particular 
	  user.
