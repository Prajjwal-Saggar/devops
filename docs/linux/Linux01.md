# Linux Fundamentals Commands 

1. **pwd** -> Current Working Directory 
2. **uname** -> Used to find the system info
3. **whoami** -> Tells about the current logged in user 
4. **history** -> This tell the last executed commands 
	* Often paired with *-n* here n is the last n commands
	* Often paired with *history | grep word* here word specifes the command with that word
	* Also with *history | tail or head* this will tell the last and first n commands 
5. **nslookup** -> This command is used to find the  info about the DNS server **Name Server Lookup**
6. **ssh-keygen** -> This is used to generate SSH public private key pair 
7. **curl**
8. **curl -o**
9. **apt-get**
10. **ifconfig**
11. **ip**
