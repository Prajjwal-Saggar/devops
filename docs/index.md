## For Anyone Starting DevOps

If you're also starting your DevOps journey, you can use these notes as a reference.

The goal isn't to learn every tool at once.

Start with the fundamentals:

```text
Linux
  ↓
Networking
  ↓
Git
  ↓
Docker
  ↓
Cloud
  ↓
CI/CD
  ↓
Kubernetes
```

Understand **why** something works before worrying about memorizing the command.

For example, don't just memorize:

```bash
ssh -i key.pem ubuntu@server
```

Understand:

```text
SSH
 ↓
Authentication
 ↓
Public / Private Keys
 ↓
~/.ssh/config
 ↓
Remote Server
```

Once the underlying concept makes sense, the commands become much easier to remember.

## Learning Philosophy

I don't want this to be a collection of commands that I memorize and forget.

The approach is:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Break something
  ↓
Debug it
  ↓
Document it
  ↓
Understand it better
```

Most of the useful knowledge comes from the **"why did this break?"** part.
