    DevOps Notes

    A personal learning space for understanding DevOps — one concept, one command, and one problem at a time.

    About Me

    Hi, I'm Prajjwal Saggar, a Computer Science student currently exploring and learning the world of DevOps, Linux, cloud infrastructure, containers, automation, and deployment.

    I created this documentation as a place to learn by doing and document what I learn along the way.

    These aren't meant to be perfect theoretical notes. They are my practical reference for the concepts, commands, problems, and workflows I encounter while learning DevOps.

    Why I Created This

    DevOps can feel overwhelming when you first start.

    You encounter things like:

    Linux
  ↓
Networking
  ↓
Git
  ↓
Docker
  ↓
Kubernetes
  ↓
Cloud
  ↓
CI/CD
  ↓
Infrastructure

    And suddenly there are hundreds of commands, tools, configuration files, and concepts to remember.

    Instead of trying to memorize everything, I wanted to build something that I could come back to whenever I get stuck.

    That's what this site is.

    For Anyone Starting DevOps

    If you're also starting your DevOps journey, you can use these notes as a reference.

    The goal isn't to learn every tool at once.

    Start with the fundamentals:

    Linux
  ↓
Networking
  ↓
Git
  ↓
Docker
  ↓
Cloud
  ↓
CI/CD
  ↓
Kubernetes

    Understand why something works before worrying about memorizing the command.

    For example, don't just memorize:

    ssh -i key.pem ubuntu@server

    Understand:

    SSH
 ↓
Authentication
 ↓
Public / Private Keys
 ↓
~/.ssh/config
 ↓
Remote Server

    Once the underlying concept makes sense, the commands become much easier to remember.

    Learning Philosophy

    I don't want this to be a collection of commands that I memorize and forget.

    The approach is:

    Learn
  ↓
Understand
  ↓
Practice
  ↓
Break something
  ↓
Debug it
  ↓
Document it
  ↓
Understand it better

    Most of the useful knowledge comes from the "why did this break?" part.
